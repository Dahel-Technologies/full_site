# Dahel Technologies Platform

This repository contains the codebase for the new **Dahel Technologies** website — a premium global EdTech and technology platform.

## The Vision
Dahel is where people learn, build, and access practical technology. We are moving away from a traditional Nigerian training company feel to a modern, outcome-focused ecosystem. 

### Key Journeys
1. **Learn**: Structured, practical courses and resources (Data Analytics, SQL, Power BI, Python, etc.)
2. **Train**: Personalized private, group, and organizational training.
3. **Assess**: Powered by **Quizarly** for testing knowledge, tracking performance, and competing.
4. **Build**: Exploring the tech Dahel builds, including AI learning tools, Quizarly, Checkamo, and Ekko Now.

## Tech Stack
- **Framework**: Next.js (App Router)
- **Styling**: Tailwind CSS v4
- **Icons**: Lucide React
- **Typography**: Inter (Google Fonts)

## Getting Started

```bash

# or
```
